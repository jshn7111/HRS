# API Blueprint

## Authentication
- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/auth/me`

## Hotels
- `GET /api/hotels`
- `GET /api/hotels/:id`
- `POST /api/hotels`
- `PUT /api/hotels/:id`
- `DELETE /api/hotels/:id`

## Bookings
- `POST /api/bookings`
- `GET /api/bookings/user`
- `GET /api/bookings/owner`
- `PUT /api/bookings/:id`
